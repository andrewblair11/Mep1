Process

Four stages, with a checkpoint after each

Your estimator signs off at each checkpoint before the next stage starts.

  1. Set up

    Sort the current, superseded and reference sets. Set scales, systems and material rules from the specs.

  2. Trace

    Mark every run and device in Bluebeam, with size and system on each markup.

  3. Check

    QC the markups against the drawings and specs. Anything missed or unsourced goes back to the estimator as a question.

  4. Package

    Build the workbook, RFI tracker and brief, then run the final package QC before handover.

Ground rules
